### 全体を貫く線

線は **2本** あり、それぞれ一度ずつしか張られていません。重複させないでください。

**線①「答えが届く」**（悩み → 解決の受け渡し）

1. 悩み（#stuck）惜しかった3パターン「銘柄は合っていた／買い値もよかった／売り時も分かっていた、でも——」
2. 結論（#stuck 末尾）「足りないのは情報の量ではなく、**答えそのもの**。『どれを買って』『いつ売ればいいのか』」
   → 見出し「利益が出ないのは、**情報不足**ではありません」の回収になっています
3. 解決（#solution）「さきほどの『答え』を、出した状態でお届けします」→ `.solved` の4行で回収

> **2026-10-19：#stuck から「4つの決断」ブロックを削除しました。**
> 「どの銘柄を／いくら入れるか／いつ買うか／いつ売るか」の4枚カードと、
> 「4つ全部当たったときだけお金は増える」という論理です。
> 先方から4回「よく分からない」と指摘があり、原因は **決断の数を数えさせる抽象的な理屈** でした。
> 惜しかった3パターン（✕リスト）が同じことを具体的・感情的に伝えているため、
> カード側は不要と判断。`.dec` `.dec-hd` `.dec-n` のCSSも削除済みです。
> **代わりに数を数えさせる構成を足さないでください。**

**線②「情報の順番」**（根拠 → 物語 → 実績）

4. 根拠（#why）「個人が知るのは最終段階のあと」（5段階タイムライン）
5. 物語（#founder）「私たちが動き終えたあとにニュースが出る」（開発者の原体験）
6. 実績（#results）「違ったのは、知っていたかどうかだけ」

> **2026-10-13：旧「同調パート（#affinity）」を削除しました。**
> 機関投資家・アルゴリズム・情報の順番の3枚カードが、線②の 4 と 5 と**同じ話を3回**していたためです。
> いちばん抽象的な言い方で先出ししており、後続のタイムラインと開発者ストーリーの威力を削いでいました。
> 唯一残す価値のあった「足りなかったのは『才能』ではなく『武器』」の一文は、#stuck 末尾へ移設済みです。
> 約4,000社という数字は #stuck の決断01と #solution に残っているため、情報の欠落はありません。

## 公開前の必須作業

### 1. 差し替え箇所

※ページ上の「要差替」表示は、フッターの事業者情報を除き削除済みです。該当箇所はHTMLコメントで残してあります。

| 箇所 | 内容 |
|---|---|
| `〈サービス名〉` | ヘッダーロゴ・フッター |
| 登録チャネル | 各HTMLの `<head>` にある `window.LP_CHANNEL` を編集（下記） |
| 実践者の声 | **許諾取得済みの実際の声（2件）に必ず差し替え**。現在は文章の見本 |
| 限定枠「先着◯名様」 | 実際に対応可能な人数 |
| フッター 事業者情報 | 商号・所在地・代表者・**登録番号**・加入協会・連絡先 |
| 各種規約リンク | 利用規約／プライバシーポリシー／特商法／契約締結前交付書面 |

### 1-A. 登録チャネルの切り替え（LINE / メール）

`index.html` と `thanks.html` の `<head>` にある設定を書き換えるだけで、ページ全体が切り替わります。

```html
<script>
window.LP_CHANNEL = {
  mode: 'line',   // 'line' か 'mail'
  url : ''        // LINE友だち追加URL または メール登録フォームURL
};
</script>
```

`mode` を変えると、以下がまとめて入れ替わります。

| 箇所 | line | mail |
|---|---|---|
| CTAボタン（5箇所） | LINEで銘柄を受け取る | メールで銘柄を受け取る |
| 受け取りステップ① | 下のボタンから友だち追加 | 下のボタンからアドレスを登録 |
| FAQ（配信停止） | ブロック・配信停止 | 配信停止 |
| サンキューページ本文 | LINEにお送りしました 等 | メールにお送りしました 等 |

`url` を設定すると、全CTAの遷移先がその値になります（空のままだと現在の `thanks.html` へのリンクが維持されます）。

### 1-B. サンキューページ（thanks.html）の設定

| 箇所 | 内容 |
|---|---|
| 表示タイミング | LINE友だち追加の直後に遷移させる（リッチメニュー／あいさつメッセージのURLに設定） |
| `<form action="#">` | 自社フォーム／CRMのエンドポイントURLに差し替え。設定するとデモ表示のブロックは不要になるので、ページ下部スクリプト内のコメント箇所を削除 |
| `<div class="slots" data-total="50" ...>` | 審査通過枠（50名）・下限・受付時間帯。HTMLのdata属性で調整 |
| `var ONE_TIME = false;` | **一度きり表示。現在オフ。集客開始時に `true` へ**（下記） |
| `※お電話は〈市外局番を記載〉より発信いたします` | 発信番号 |
| 「個人情報の取扱い」リンク | プライバシーポリシーのURL |

**フォームの送信項目**：お名前／電話番号／連絡希望時間帯／投資経験（任意）／投資可能資金（任意）／同意チェック

電話番号は `0` 始まり10〜11桁でバリデーションしています。同意チェックは必須です（個人情報保護法の観点で、外すことは推奨しません）。

### 1-C. 「一度きり表示」の再開手順

現在は**機能・文言ともにオフ**です。集客を開始するタイミングで、`thanks.html` の `<head>` にある1行を変えてください。

```js
var ONE_TIME = true;   // false → true
```

これだけで、以下が**同時に**復活します。

- 一度開いた端末では、2回目のアクセスで「受付終了」画面（全画面）に切り替わる
- 「このページが表示されるのは、この一度きりです」の警告セクション
- 「このページを閉じた時点で、受け取る方法はなくなります」
- 「※このご案内は、今回かぎりの表示です」
- 追従ボタンの「＼ 今回かぎり・先着300名様 ／」

**文言だけが先に出てしまうことはありません。** フラグ1つで機能と文言が連動します。

確認時は URL に `?again=1` を付けると記録をリセットできます。

※端末内（localStorage）判定のため、別端末やシークレットモードでは再表示されます。厳密に1回だけにする場合は、LINE側の使い捨てURL＋サーバー側のトークン失効と組み合わせてください。

## 法務まわり（弁護士確認用の申し送り）

最終確認は貴社顧問弁護士にお任せしますが、**指摘が入りやすい箇所**を先に洗い出しておきます。

1. **実績価格のエビデンス**
   掲載した10銘柄の株価は、東証の四本値・各社IR等と**必ず突合**してください。
   ご提示いただいた数値には、当方の把握する株価水準と乖離があるものが含まれます
   （例：キオクシアHD 112,700円、太陽誘電 24,065円、イビデン 27,480円）。
   金商法38条・広告規制で最初に見られるのがここです。

2. **「いつ推奨し、いつの価格か」の明示**
   現状は「※記載の価格・騰落率は〈掲載期間を記載〉における…」というプレースホルダーです。
   *実際に会員へ配信した日付*と、その時点の株価であることを明記してください。

3. **著しく事実に相違する／有利と誤認させる表示の禁止**（金商法37条）
   「今すぐ急騰する」「必ず」等の断定的表現はリスクが高い語です。
   本文中の表現は、顧問弁護士の判断で置換できるよう平文で記述しています。

4. **登録の要否**
   個別銘柄について助言を行う場合、**投資助言・代理業の登録**が必要になるのが原則です。
   フッターに登録番号欄を用意してあります。

5. **シミュレーションの位置づけ**
   「100万円を投資した場合」は過去実績からの単純試算であることを明記済みです。
   将来利益の予測と受け取られないよう、注記の文言もご確認ください。

6. **お客様の声**
   体験談は景表法（No.1表示・打消し表示）の論点になります。許諾取得と「個人の感想」注記を必須に。

7. **既に本文に入れてあるリスク開示**
   元本割れの可能性／過去実績は将来を保証しない／情報提供であり売買推奨ではない／
   最終判断は自己責任／手数料・税金未考慮／無断転載禁止 — フッターに集約しています。
